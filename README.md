# 爬拍所｜CHW 紫曜系睫角守宫竞拍市场

一个独立品牌的前端竞拍市场，首屏聚焦 CHW 紫曜系首发拍品。页面包含拍品浏览、筛选、倒计时、阶梯加价、AI 代理竞价、¥50 账户保证金、竞拍记录、规则说明与钱包状态。

在线访问：<https://mcp.edgeone.site/share/l3v7T8kp31kvKS9-PhWKQ> · 源码：<https://github.com/leixianya/gecko-auction>

金额、账户余额、热度与竞拍者由浏览器端状态驱动；页面不采集支付、银行卡或身份信息。图片来源与许可记录见 [`assets/ATTRIBUTIONS.md`](assets/ATTRIBUTIONS.md)。

## 本地预览
